# Unknown Pass｜先探索方向性未知

**來源修訂：2026-09-06｜第二輪檢查後修訂；原文未標語意版本**
**Claude port：2026-09-15｜來源 `chatgpt/skills/unknown-pass` @ 0e85a78｜差異：移除 ChatGPT 專屬交班路由句，其餘原文保留**

辨識「答案不同就會改變解法」的未知，決定是否已足以行動。輸出與釐清的深度以當次決策需要為準。

## 何時使用

使用者明確要求 Unknown Pass，或問題定義、關鍵假設、成功條件仍不清楚而會改變解法時使用。高風險決策中未解的證據、權限或不可逆風險，屬於方向性未知。
題目提到系統、醫療、政策、研究或新工具，本身不足以啟動完整流程。已指定內容與限制的改寫、翻譯、摘要、格式修改，以及已定案步驟，直接完成。

## 選擇深度與參考

- 輕量：少數方向性未知。用簡短問題理解、關鍵未知及前進判斷即可。
- 標準：多種合理問題定義，選錯會造成重工。需要探索時讀 [診斷指引](references/diagnostic-guide.md)，只選能改變方向的檢查。
- 深度：重大安全、不可逆、資源或治理決策。補上決策條件、證據需求、替代路徑、最壞情境與必要人類核准。
- 需要理解方法如何套用時讀 [使用範例](references/examples.md)。範例中的專案與 AI 分工只適用於該情境。

選定的深度決定適用流程與輸出；標準／深度的項目不自動套到輕量任務。參考不可取得時，用本檔完成可支持的範圍並說明限制。

## 必要判斷

1. 用最少充分背景說明真正要決定或交付什麼；只列確實合理的不同問題定義，數量不限。
2. 區分已確認事實、合理推論、工作假設、方向性未知與非阻塞缺口。依實際來源說明，不補造數字、內部流程、現場人員立場或使用者默會知識。
3. 找出會改變目標、架構、風險、成本或執行方式的假設。沒有發現額外隱藏假設時如實說明。
4. 對方向性未知判斷：必須先確認、可採假設前進，或可稍後補充。只有真正阻塞時才詢問最重要問題；不把所有缺漏都交回使用者。
5. 不自行替使用者接受風險、做價值取捨或增加新制度。只有有助於解除關鍵未知時才建議研究、訪談或新工具。

## 輸出與完成條件

使用 `[Unknown Pass]` 或 `[Unknown Pass｜Light]`，依需要呈現問題理解、重要事實／假設、方向性未知及以下一種判斷：

- **可直接前進**：核心問題、成功條件與限制已足夠清楚。
- **可採假設前進**：列出暫定假設、影響與下一個驗證點。
- **先確認關鍵問題**：指出哪個答案會改變哪個決策，提出最重要的問題。

這個階段在方向判斷及下一個可行動作清楚時完成。沒有需追問的問題就明說，不為固定格式填寫空段。

若使用者的整體任務還包含產出或執行，且已可前進，接續完成已授權工作；只要求釐清時則交付判斷，不擴張執行範圍。使用者要求先產出時，在合理假設下先交最佳可行版本，並標明待補處；必要安全與正式核准仍保留。

## 停止、失敗與後續

來源不足時說明已讀範圍。若缺少法律／安全可行性、重大資源或不可逆決策所需的關鍵事實，先準備可審閱的選項與影響，保留依賴該決策的操作，仍可做不依賴它的工作。
只有出現新的方向性未知才重開釐清，不反覆重做已確認部分。

需要時才使用目前介面可用的 `multi-perspective-reviewer` 或 `evidence-red-team-reviewer`；未安裝時以本次任務的最小可行方式前進並標示限制。
