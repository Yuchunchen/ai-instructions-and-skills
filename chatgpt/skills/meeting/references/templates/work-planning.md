# 工作規劃／Sprint模板

案內按「目標 → 已承諾工作 → 責任 → 期限 → 依賴／阻礙」整理。未承諾構想可記於討論，不能列成已交辦。依賴要有來源，不憑一般常識補出前後工作關係。

預設一般工作規劃。只有明示採Sprint／敏捷流程，才使用來源中已有的Sprint資訊；即使是Sprint，也不推算點數、產能、Velocity或完成標準。一般行政工作不套Code／Test／QA等軟體欄位。承諾執行不勾成已完成。

## 正式紀錄的案內格式骨架

```text
第〔案號〕案：〔案由〕
現況與目標：〔來源明示的工作背景及目標〕
討論摘要／主要爭點：〔分工、時程及其他討論中的不同意見〕
決議：〔已確認的安排；未形成決議則如實標示〕
已承諾工作：〔A編號、工作、主責、協辦、期限、執行狀態、回報方式〕
依賴／阻礙：〔只列來源已有的先後條件或阻礙〕
來源：〔既有時間戳／段落／原文短句〕
```
