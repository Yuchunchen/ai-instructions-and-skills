# 進度回報模板

案內按「已完成 → 進行中 → 後續工作 → 阻礙／需要支援」整理，以來源狀態分類；尚未提及執行狀態的已交辦工作只放後續工作，不自動移進進行中。

紅黃綠燈、完成百分比、目標差距須有來源或明確計算依據；使用計算值時標「依來源計算」並交代分母／公式。沒有狀態判準就不自設燈號。幾件工作完成占比不等於專案實際進度；口語「大概一半」保留約數。

## 正式紀錄的案內格式骨架

```text
第〔案號〕案：〔案由〕
現況與目標：〔來源提及的進度背景〕
已完成：〔有完成依據的事項〕
進行中：〔來源明示正在執行的事項〕
後續工作：〔已交辦工作；狀態未提及不能算進行中〕
阻礙／需要支援：〔來源提出的問題、影響及異議〕
決議：〔本案明確決定；未形成決議則如實標示〕
來源：〔既有時間戳／段落／原文短句〕
```
