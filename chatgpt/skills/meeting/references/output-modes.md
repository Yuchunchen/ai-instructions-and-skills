# 輸出用途與組合限制

未指定用途首次用正式紀錄；後續只改明示維度。所有整理稿都遵循同一份來源事實，切用途不補新事實。預設「【草稿／待覆核】」及精簡而真實的資料來源；短版的這些文字也算字數。除有明確數字或「精簡版」，不自加固定字數上限。

| 命令 | 對象／用途 | 交付內容與限制 |
| --- | --- | --- |
| 正式紀錄 | 核閱、留存、追蹤 | 讀 formal-format.md，完整外框及基本欄位，逐案討論、決議、待辦、待確認，保留重要異議與來源。 |
| 300字／精簡版 | 快速掌握結果 | 未另指定字數時上限300字；結論、重要工作、責任／期限、未決事項優先，不湊字數，不列全套章節。其他明示上限優先。 |
| LINE版 | 內部同仁／與會者 | 短標題＋短段落或條列，聚焦重點、決議與誰做什麼，可保留必要內部資訊，無表格。 |
| LINE版公開 | 不限定閱讀對象／可能轉傳 | 一般人能理解的用語，僅對外有用結論與安排；移除個資、聯絡資料、內部評議、不必要歸責及敏感引文，無表格。未定安排保留未定，不宣稱已核定公告。 |
| LINE版報告 | 上層長官／機關 | 依「報告主旨 → 目前情形 → 已辦事項 → 後續辦理／請示事項」順序，正式簡潔客觀，無表格。無已辦或需請示依據時省略該小段，不補虛構事實、客套或請示。 |
| 主管版 | 掌握情勢與決策 | 結論先行，突出實際需決定事項、來源提及的阻礙／影響、下一步；未涉及裁示就據實整理，不自造需要主管批准的流程。必要時可用表格。額外建議另標「分析建議（非會議決議）」。 |
| 待辦清單 | 分派／執行追蹤 | 每獨立工作一列，含A編號、工作、負責人、期限、狀態、必要來源；有協辦／回報方式則保留。依要求分組；LINE組合用條列。缺漏、未定、執行狀態不得推定。 |
| 待確認 | 人工覆核 | Q編號列疑字、矛盾、未定責任與期限，附原文／定位及具體確認問題。沿用Q編號，可逐項回答後重產；不覆蓋上一份成品用途。 |
| 會議檢視 | 改善會議與紀錄品質 | 依來源檢查決議是否清楚、交辦是否完整、問題有無回應、分歧有無處理；另列改善建議，不當成會議決議。不覆蓋上一份成品用途。 |

## 命令組合

- 「用進度回報模板，做成LINE版報告，300字內」＝進度內容重點＋向上報告用途＋無表格＋300字上限；沒有已完成證據就不產生已辦事項。
- 「改用決策模板，重新產生主管版」＝重新組織同一場的問題、選項、決議，改成主管閱讀；未取消的明確字數限制仍沿用。
- 「主管版，用LINE格式」＝主管重點＋LINE無表格；不強套LINE版報告的四段。
- 「待辦清單，依負責單位分組」＝分組但仍一個工作一列；分組標題不能取代缺漏的主責欄位。
- 「LINE版報告，並附逐字稿」＝一份整理稿及一份原稿；不同來源性質分開標示。
- 「待確認」後接「Q1已確認……重新產生」＝重產上一份成品，未確認Q保留；不再次只給Q清單。覆核清單不沿用成品的字數上限，除非本輪另有要求；重產成品才恢復既有上限。
- 單純「顯示其他適合的模板」或「只要逐字稿」不更改已選模板、上一份成品用途及字數限制。

## 會議檢視的邊界

只在使用者要求時執行。以「來源觀察 → 對紀錄／追蹤的影響 → 分開列出的改善建議」呈現，不替參與者判定人格或心理狀態。

沒有可靠說話者識別與精確發言時間，不計個人發言時間比例；文字字數比例不是發言時間比例。打斷需有可靠重疊語音／說話者證據；段落順序不足。每分鐘贅詞須有保留贅詞的原稿與時間分母；摘要不能拿來反推。保留語氣不等於逃避衝突。多場趨勢只限已提供且可比較的會議。

## 300字校驗與公開稿

非空白Unicode字元計數，含標點、標題、英文、數字、草稿／來源標記、正文格式符號；不計空白／換行或獨立附件。腳本成功僅代表字數合規；仍須核對語意、條件、疑義與LINE無表格。

公開稿的去識別與未定條件不能為縮短而丟失。公開範圍不明的敏感細節省略，必要時簡示需確認公開範圍；仍可完成其餘安全、可理解的公開草稿。「LINE版」是撰稿樣式，不表示已傳送LINE訊息；「正式」或「公開」也不表示已核定、發布或寫入外部系統。
